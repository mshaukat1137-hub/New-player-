# Simple Video Player APK Source

This is a basic Android video player app source code.

## Features
- Play video from direct URL
- Pick and play a video from phone storage
- Playback controls using ExoPlayer

## How to build APK
1. Install Android Studio.
2. Open this `video-player-app` folder.
3. Let Gradle sync finish.
4. Run on device/emulator, or build APK via:
   - **Build > Build APK(s)**
